QR Barcode Reader

Develop a QR Barcode Multi Scanner and Inventory front end. Automated inventory data collection and created a workflow for collecting, storing and analyzing data. Build the application using Node.js. The system allocates results in a locally structured inventory database using MongoDB database. Analyzed collected inventory and sales data to identify, top selling items, stock management, purchasing decisions and sales trends. Implemented a QR code reading locking mechanism to prevent duplicate entries during continuous scanning and improve data accuracy.

The QR Barcode Multi Scanner uses OpenCV (Open-Source Computer Vision) library to manipulate live video input from a Logi Tech 720p Webcam.

I got to develop an inventory management system using tools such as Node.js and MongoDB to build and manipulate inventory data.

The system automatically collected, labeled and organized data, which helped reduce manual entry and gave analysis capabilities to make informed decisions.
